Les données ne se chargent pas.

Cette page lit quatre fichiers JSON dans data/. Un navigateur bloque ces lectures quand la page est ouverte directement depuis le disque (file://).

Deux solutions : publier le dossier sur GitHub Pages, ou lancer un serveur local depuis le dossier du site :

python3 -m http.server 8000

puis ouvrir http://localhost:8000.

    Battements par kilomètre : fréquence cardiaque moyenne × durée d'un kilomètre. Plus le chiffre baisse, plus tu deviens économique. C'est l'indicateur qui compte le plus en ce moment, parce qu'il neutralise l'allure et le terrain plat ou vallonné.
